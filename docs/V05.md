# v0.5 professional expansion
Five diagram types, deterministic rendering, manual node-position adjustment (except sequence), BPMN additional task/event/gateway types, secure single-owner session mode, BRD/FRD/SRS document selection, RICE/ICE calculators and test readiness.
Cloud sessions are in-memory, expire in 12 hours, and are invalidated on restart. Existing APP_USERNAME and APP_PASSWORD remain deployment secrets; no public signup. Login throttling is global for this single-owner deployment.
ERD uses explicit numeric cardinality labels, not full crow's-foot notation; sequence supports ordered messages/replies, not combined fragments; activity is a limited subset. BPMN is not a complete executable BPMN implementation.
Database remains per-project JSONB with server change log. Prisma normalization, full UAT sign-off, AI provider integration, full BPMN notation and screenshot-baseline regression remain outstanding. Review suggestions are deterministic, not AI.
Playwright smoke tests exercise navigation, language, diagram preview and mobile width. Verify actual hosted Neon migration, Office export pagination and browser compatibility before using confidential records.
